# docs

Study material for the AEB project — open the `.html` files in a browser.

| File | What it is |
|---|---|
| [visual-walkthrough.html](visual-walkthrough.html) | Six hand-drawn diagrams: node graph, sensor fusion, the Kalman-filter loop, the state machine, the two brake gates, and a run timeline. Each has a line to say out loud. |
| [interview-notes.html](interview-notes.html) | Text companion: the 30-second pitch, architecture table, the maths, design rationale, known limitations, and likely interview questions with answers. |

Both are self-contained (Google Fonts only) and render light/dark.
